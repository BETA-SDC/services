隐私保护政策

版本及生效日期：2026 年 10 月 19 日。适用于 BETA SDC 账户中心及使用统一账户的导航、个人主页和日历站点，由 BETA SDC 账户服务维护团队维护。隐私咨询、查阅、更正、删除、撤回同意及账户注销申请，请联系 betasdc@163.com。申请时需要核实账户归属；请勿在普通邮件中附完整证件号码。

1. 我们处理哪些信息

创建账户需要姓名、校园邮箱、邮箱验证信息及密码；昵称可选。同一校园邮箱（不区分大小写）只能对应一个账户。密码只保存不可逆的加盐哈希；姓名、昵称、邮箱及账户权限资料不是本政策所述的字段加密资料。

学号为注册必填的一般个人资料，用于账户资料及您主动授权的签到快捷填写；电话号码和证件信息仍为可选私密资料，不填写电话或证件也可以注册和登录。学号在“个人资料”中管理，本人登录后即可查看、修改，但不能清空或单独删除，无需二次验证；仍加密保存，不在公开主页展示。已有账号缺少学号不影响登录，可在个人资料中补充。证件类型、签发国家或地区、号码及格式检查结果按一个证件字段保存。证件号码可能属于敏感个人信息，泄露可能造成身份冒用、诈骗等风险；请仅在确有个人资料保管需要时自愿填写。本站目前不要求用证件注册，不要求上传证件照片，不调用实名数据库、不进行人证比对；如无必要，建议不保存证件信息。

证件检查仅在支持的证件类型上检查长度、字符、日期或校验位；其他类型只检查格式。学号未与学校数据库核对。电话号码仅支持中国大陆 11 位手机号，无需填写 +86，未进行短信验证。任何“校验通过”均不代表证件真实、有效或属于当前用户。

2. 处理目的和单独同意

本节的私密资料操作规则适用于电话与证件。学号按注册必填的一般个人资料管理，可在“个人资料”中登录后直接查看、修改，无需二次验证或私密资料单次授权，但不能清空或单独删除；不因这一设置而对外公开。学号在签到记录的基本名单中可由有权限的登录成员直接查看，导出仍需 PAT。

个人主页在校园网络访问范围内对其他访问者展示昵称（未设置时使用注册编号）、头像、您主动保存的公开简介，以及已绑定的 GitHub 账户链接；不展示真实姓名、校园邮箱、学号、电话、证件或管理权限。请勿将私密信息写入公开简介。主页默认使用系统生成的注册编号作为路径，不使用姓名或昵称；自定义地址经管理员审核后生效，历史地址保留以避免旧链接失效。头像通过 GitHub 提供时，浏览器将访问 GitHub 头像服务；未绑定时使用本站默认头像。

账户中心负责统一登录。切换至导航、个人主页或日历时，经账户中心签发最多 60 秒、限当前目标站点且仅能使用一次的登录凭据；各站使用自己的安全、HttpOnly、仅当前主机 Cookie，不把密码、通行密钥或私密资料传给其他站点。站点会话最长不超过账户中心会话期限；在账户中心退出将撤销关联站点会话。登录共享不等于授权其他站点读取私密资料，隐私资料和通行密钥管理仍仅在账户中心进行。日历继续按原有查看、编辑权限限制数据。

可选资料用于您在本账户中心自行保管、查看、更正和删除；您也可另行单独同意将本次签到需要的学号、手机号、证件资料填写至签到表单，具体范围、接收方和保存期限见下方“活动签到”。在账户设置中直接选择“隐私资料”即可进入。点击“二次验证并查看全部”表示单独同意本次读取全部私密资料并在当前页面展示；点击“保存修改”表示同意加密保存本次提交，删除另有确认。按钮旁会告知目的、范围及接收方，不需要逐字段勾选。拒绝不影响基本账户功能。查看、修改和删除必须通过已登记通行密钥或绑定邮箱的一次性验证码完成二次验证；账户密码和“邮箱已验证”状态不能代替本次验证。验证在当前登录会话内最多 5 分钟有效，每次资料操作仍需独立的 60 秒单次授权。保存表示同意在您删除前继续加密保管，不表示同意未来任意调用。

每次账户私密资料操作只签发绑定当前账户、当前登录会话、资料范围及操作目的的随机授权，60 秒后失效，最多使用一次；服务端只存授权摘要，不能用于另一账户、会话或目的。修改或删除会撤销尚未使用的资料授权。签到发起人不能直接浏览账户设置中的私密字段；您另行同意提交的独立签到资料适用下方活动签到规则。其他应用或接收方的新增用途需要另外告知并征得必要的同意。

单次授权限制的是服务端的一次请求，并不等于已展示的信息无法被截图、复制或缓存。页面会在 5 分钟后、切到后台或离开页面时隐藏本次展示，但不能收回已经被看到的信息。请不要在他人设备或共享环境查看完整号码。

3. 加密和访问保护

访问使用 HTTPS。可选资料按字段使用 AES-256-GCM 认证加密，独立随机密钥不写入数据库；每次加密使用新随机数，并绑定账户和字段以检测篡改。数据库和密钥文件使用服务账户的受限权限，普通管理员页面不展示可选资料，业务审计不记录号码明文。登录、CSRF 校验、网络限制及操作限流共同约束访问。

这是服务器端加密，不是端到端加密，也不是零知识存储。密钥和应用运行于同一服务器，拥有服务器最高权限的人、受控制的运行时或失陷的终端仍可能接触明文；加密无法消除所有风险。请勿将本站作为唯一证件保管位置。若发生泄露或其他安全事件，维护团队会采取处置措施，并根据实际情况及适用要求通知受影响用户。

4. 通行密钥与设备验证

通行密钥自愿添加，入口与邮箱验证码统一位于“双重验证（2FA）”。添加、移除需先登录对应账号、验证账户密码并完成本次二次验证；首次添加可使用绑定邮箱验证码。建议使用设备的指纹或面容验证。本站保存凭证标识、公钥、签名计数及登记时间，不接收或保存指纹、人脸模板或系统 PIN。设备决定采用生物识别、PIN 或其他本地验证方式；本站不能保证每次一定使用生物识别。设备或密码管理器可能按其设置同步通行密钥，受其自身隐私条款约束。添加后，可直接使用设备上保存的通行密钥登录其绑定账号，无需输入邮箱，也可用于私密资料验证；邮箱密码登录仍保留。通行密钥登录本身不自动读取私密资料。移除后对应密钥不可再登录本站。

5. 保存期限、删除与备份

可选资料保存至您自行删除、清空所选字段或账户注销处理完成。可在账户页随时更正、删除，并停止未来处理；已经完成的处理不能撤回。账户注销暂由邮件申请处理，不代表点击资料删除即可注销整个账户。

资料操作及同意记录包含账户标识、操作、字段名称、政策版本和时间，不含号码明文；在后续资料操作时清理超过 180 天的记录，停止使用时旧记录可能在下次操作或维护清理前仍有保留。定期数据库备份保留最近 14 份，可能另有受限的升级恢复快照。删除后，旧密文可能在受限备份中暂存，随备份轮换或维护清理移除，不再用于日常业务；若灾难恢复，维护人员应先核对并重新执行删除申请。密钥需要独立安全备份，遗失后无法解密。

6. 其他数据流

邮箱验证码通过 betasdc@163.com 发出，邮件服务会接触收件地址及邮件内容，但不发送本页的学号、电话或证件信息。二次验证码 5 分钟内有效，绑定发起验证的登录会话，最多尝试 5 次，发送间隔至少 60 秒；验证码只在待发邮件队列中短暂明文保存，发送成功或失效后清除，核验记录使用带密钥摘要。自愿绑定 GitHub 时会向 GitHub 发起授权请求，并保存该授权允许返回的账户、组织及 Team 信息，用于展示和权限同步；GitHub 是外部服务，您也可不绑定或解除绑定。本站不出售私密资料，不将其用于广告，不自动发送给 GitHub、邮件服务或其他应用。

7. 活动签到

签到单独同意版本：checkin-2026-10-19-v5。有效 BETA-SDC 成员及管理员可以发起签到并选择本活动必要的姓名、邮箱、学号、手机号、证件，以及最多 8 项自定义必填文本条目，至少包含一个防重复标识。发起人应仅在用途确有必要时收集证件，禁止利用自定义条目索取密码、验证码、支付资料等无关信息。证件号码可能涉及敏感个人信息，泄露可能造成身份冒用、诈骗等风险，参加者应在明确用途和必要性后自愿提交。扫码页面会显示活动、发起人的真实姓名、使用目的、采集字段、开放时段、管理员及获批限时查看者的接收范围、长期保存说明。独立介绍页默认仅公开活动标题、介绍、发起人真实姓名和签到总人数，发起人或管理员可收紧可见范围；该设置不公开签到者信息。签到不是账户注册，未注册访问者也可自行填写；不会因此自动创建账户，不收集定位或生物信息。拒绝签到不影响基本账户功能。姓名、联系方式和证件不进行官方身份核验，证件只检查支持类型的格式或校验位；登录标记不代表到场核验。可关联日历事件以填写活动信息，内部日历编号不通过公开扫码接口提供。

注册用户只有主动选择“使用已保存资料”、确认本活动和字段范围后，才会签发绑定本账号、本会话、本活动、60 秒内有效且仅用一次的读取授权。读取手机号和证件需通过现有通行密钥或绑定邮箱二次验证，仅使用姓名、邮箱和学号时不需要二次验证。不会读取签到未要求的资料，自定义条目需手动填写；读取仅填入当前浏览器，不会自动提交。您核对并单独勾选同意后，提交动作才会将本次填写的信息保存到该活动的独立签到记录；手动填写同样需要同意。拒绝不影响基本账号功能。账户资料的更改或删除不自动更改已经提交的独立活动记录。

签到时间以服务器 UTC 时间记录，界面及导出显示北京时间；不接受浏览器提交的时间。记录包括所选信息、签到编号、政策版本、服务器时间，以及已登录时的内部账号关联。浏览器仅保存签名保护的签到回执标识，不在本地存储中保存签到资料。防重复标识使用带密钥、活动隔离的摘要；已提交信息和签到链接密钥使用现有服务端 AES-256-GCM 加密。该措施不能防止知晓他人信息的人冒填、转发二维码、代签或同一人变更所有未验证信息再次提交。

基本名单包含姓名、邮箱、学号、签到时间及提交方式，由已登录且有活动查看权限的发起人、有效 BETA-SDC 成员及管理员直接查看，不需要 PAT 或二次验证，不向公众开放。电话、证件及所有自定义条目属于受保护字段；查看这些字段和任何导出均需提交用途，经管理员二次验证并选定到期时间批准后，领取绑定本人账号、已验证邮箱和签到表的 PAT，读取时还需本人二次验证。管理员也不能绕过该要求。普通成员直接查看仅包含 v5 同意记录；获批 PAT 可查看 v4/v5；更早记录仍仅管理员可见，不改写旧版同意。导出仅限管理员且 PAT 须明确允许导出。

PAT 最长 7 天有效，仅通过 BETA SDC Service 邮件发送；校验摘要保存在数据库，待发送正文加密保存，邮件不附签到者资料。到期、撤销、邮箱变更或审批管理员权限失效后拒绝受保护读取；重发使旧 PAT 失效且不延长有效期。有效期内允许多次分页读取，不等于账户资料的 60 秒单次授权。切到后台或离开页面会清空资料和 PAT，不能远程收回截图、抄录或下载文件。申请、审批、密钥、撤销、到期和删除通知通过系统邮件发送，SMTP 接收不保证收件箱送达，请勿转发密钥邮件。所有答案仍加密保存，不得擅自转发或另作他用。发起人可修改介绍和可见范围；暂停、更换链接、直接删除及审批由管理员操作，删除及审批仍需二次验证。

活动和签到记录为活动档案长期保存，不按固定天数自动删除，直至管理员人工删除。普通成员删除自己创建的签到表需提交原因，由管理员审核；批准后删除该表及全部签到记录，驳回则保留。删除申请、申请原因、审核人、结果和时间作为管理记录保留，不包含已删除的签到答案。参加者需要查阅、更正、撤回同意或删除单条记录，请联系 betasdc@163.com，提供签到编号并完成必要的归属核实，请勿发送完整证件或他人信息。此版本的保存期限及接收范围仅由本次明确同意授权；旧版同意记录保留原版本，不视为用户已经同意扩大用途或长期保存，维护方应对历史资料另行告知和确认。受限备份的暂存和轮换仍适用第 5 节。服务器最高权限及已导出文件的风险仍适用第 3 节。

8. 适用限制及政策变更

本账户中心不是学校官方身份认证系统。未满 14 周岁的用户请勿自行提交可选敏感资料，应先联系维护团队处理监护人同意事宜。政策重大变更将更新版本和生效日期；涉及新用途、接收方或范围时，需要重新取得必要的同意，而非默认延用旧授权。
